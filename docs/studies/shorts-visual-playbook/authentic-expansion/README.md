# Caleb and Lewis: broader format foundations

Version `2026-09-10.3`. Four additional Caleb Ralston reels and four additional
Lewis Mudrich reels expand the current September comparison set from **three
to seven each**. The original six were a contrast sample, not evidence that
three examples captured either creator's full range. The older July Caleb
study is a separate cohort and is not included in this count.

Start with [Format foundations](../FORMAT_FOUNDATIONS.md). These eight cases
retain each complete narrative and explain when a format helps, how it develops,
what a good adaptation needs and why it ends. They deliberately include both
useful decisions and limitations. They are reference context, not fine-tuning data
or a set of creator imitation presets.

| Case | Message/format being studied | Important contrast |
| --- | --- | --- |
| [CR04 · Explain an exercise through the conversation](cases/CR04.md) | A differentiation exercise explained through interview delivery, gestures and listener views. | Mentioning a worksheet does not automatically require a diagram; the worksheet itself is not visibly demonstrated. |
| [CR05 · A reading card over quiet personal footage](cases/CR05.md) | A career chronology over a stable seated laptop shot. | A reading card needs different pacing and text density from a spoken lesson. |
| [CR06 · Numbered questions without leaving the interview](cases/CR06.md) | Four questions organized with brief large ordinals. | Section changes can happen inside a coherent performance format. |
| [CR07 · Build a relationship diagram, then return to conviction](cases/CR07.md) | Problem + solution → idea → angles → content, then full portrait for qualification. | Same podcast context as CR04; the relationship earns the diagram. This reel is a collaborative post appearing on Caleb's profile. |
| [LM04 · Physical teaching prop, chapter changes and a tangible offer](cases/LM04.md) | Ads procedure supported by physical cards, chapter cues and a real guide preview. | Multiple simultaneous text layers compete; physical activity does not verify performance claims. |
| [LM05 · Personal montage with a text-led narrative](cases/LM05.md) | Departure tension and personal stakes carried by stable passages across changing footage. | The answer is deferred to another post, so this is a weaker model for a self-contained teaching payoff. |
| [LM06 · A workflow of artifacts above the presenter](cases/LM06.md) | Examples → metrics → headline change → diagnostics → result. | Requires traceable inputs/results and readable detail. A tiny or fast-scrolling capture can fail its job. |
| [LM07 · A website argument that stays with the person](cases/LM07.md) | Trust and proof placement explained through walking delivery and gestures. | Same broad website topic as LM06, different viewing need. A screen capture is conditional on the lesson. |

The expansion contains **8 sources, 39 directing beats, 541 chronological samples
across 49 coverage sheets, 213 unique full-resolution selected source frames,
and 13 native-frame motion bursts**. Five accepted local machine transcripts are
retained. All coverage sheets and bursts were visually inspected; 12 selected
frames were also inspected individually at original resolution. These are separate
counts, not 39 unique templates or 541 independent examples.

Each JSON case stores original public URL, local source media, acquisition/hash
receipts, complete coverage pointers, decoded frame index/PTS, observations,
interpretations, approximate editorial boundaries, alternatives and review scope.
Each Markdown case pairs those notes with source sequences and full-frame links.

# Complete story with authentic page B-roll

## Why this run exists

The preceding 3996 gallery qualified product identity marks and policy behavior.
Its 10.88-second excerpt did not teach the complete next action. Correct logos,
valid frames and a successful export were insufficient evidence for a complete
visual story. The operator explicitly requested integration of the whole lesson
with real website motion.

## Shared workflow changes

- All Short directions now start with a source-supported question, development
  and payoff, and require a complete native build to author `strategy.story`.
  Component tests must identify their narrower scope.
- The optional native story contract binds every existing pacing beat to its
  scene, continuity object, actual media/graphic target and readable hold.
  Existing projects stay readable and report story status as unplanned.
- Logos cannot fulfill real-artifact or real-operation jobs. An operation must
  have a selected demonstration video, actual output action/result checkpoints
  and a result reading hold. Semantic truth and finished review remain separate.
- Public-page inspection can start at a specific observed section; h1–h6 headings
  are available for target selection. This does not bypass access restrictions.
- Fresh recording now has a demonstrated automatic capture-to-origin path,
  preserving its exact source URL, original pixels and frame clock.

It uses three complete passages from the operator's original C0679.MP4 and its
already pinned local transcript. Shared rational clocks and caption grouping
preserve the source identity and original playback speed.

title is “Why can't you get useful ideas from AI?” The strategy compares three

The file diagram is illustrative; it is not documentary customer footage or

# Hook anchors

A hook anchor names the move an opening makes. A template in straight double quotes can
be filled literally, slot by slot. A template without quotes describes a move that needs
editorial adaptation to the speaker's words; it cannot be slot-filled mechanically.

Every slot value must come from the speaker's retained words or the confirmed brief.

### 1. TEASE — hold back the answer the viewer came for
| Anchor | Template | Notes |
|---|---|---|
| `tease-hidden-reason` | "The real reason [result] happens isn't what you think" | use only when the source gives the real reason |
| `tease-what-changed` | "One thing changed, and [result] followed" | the one thing must be named later in the Short |
| `tease-the-part-people-skip` | "Everyone does [task]. Almost nobody does this part" | the skipped part is the payoff |
| `tease-until-you-see` | Show the result first and hold the explanation until the viewer has seen it | picture-led; needs the result on screen |

### 2. QUESTION — ask what the viewer is already asking
| Anchor | Template | Notes |
|---|---|---|
| `question-ever-wonder` | "Do you ever wonder why [frustrating pattern]?" | the Short must answer it |
| `question-why-does` | "Why does [surprising thing] keep happening?" | the surprise must be real to this audience |
| `question-what-if` | "What if [common assumption] was the problem?" | the source must argue it |
| `question-would-you` | "Would you rather [option A] or [option B]?" | both options must be real |

### 3. CONTRARIAN — disagree with the usual advice, for a reason
| Anchor | Template | Notes |
|---|---|---|
| `contrarian-stop-advice` | "Stop [common advice]. Here's why" | the reason is the Short |
| `contrarian-overrated` | "[Popular thing] is overrated for [audience]" | narrow the audience; don't dismiss everyone |
| `contrarian-opposite-worked` | "I did the opposite of [usual advice] and [result]" | first-person result required |
| `contrarian-fair-statement` | State the usual view fairly in one line, then the speaker's disagreement | adaptation; not literal |

### 4. CALL-OUT — name who this is for
| Anchor | Template | Notes |
|---|---|---|
| `callout-if-you` | "If you [specific situation], watch this" | the situation must be specific |
| `callout-for-audience` | "[Audience]: this one is for you" | name an audience narrow enough to feel addressed |
| `callout-not-your-fault` | "If [struggle] keeps happening, it's not you. It's [cause]" | the cause must be in the source |
| `callout-symptom-list` | Name two or three signs the viewer will recognise, then say what they mean | adaptation; not literal |

### 5. CONFESSION — admit something first
| Anchor | Template | Notes |
|---|---|---|
| `confession-got-wrong` | "I got [thing] wrong for [time period]" | the time period makes it credible; state it |
| `confession-almost-quit` | "I almost stopped [activity] because of [problem]" | the problem must be the one the Short solves |
| `confession-embarrassing-number` | "My first [attempt] made [small number]" | the number must be real |
| `confession-cold-open` | Open mid-scene on the moment it went wrong, then rewind | adaptation; picture-led |

### 6. PROOF — let the evidence open
| Anchor | Template | Notes |
|---|---|---|
| `proof-specific-number` | "[Specific number] [unit] in [time period]" | never round or inflate |
| `proof-before-after` | "From [before state] to [after state]" | both states must be evidenced |
| `proof-show-it-working` | Show the thing working on screen before saying anything about it | picture-led |
| `proof-what-it-took` | "Here's exactly what it took to [result]" | list the real inputs; no hidden steps |

### 7. VALUE — promise a usable outcome
| Anchor | Template | Notes |
|---|---|---|
| `value-how-to` | "How to [outcome] (even if [obstacle])" | the obstacle clause is optional |
| `value-formula` | "The formula is simple: [X] plus [Y]" | both parts must be named in the Short |
| `value-in-one-minute` | "[Skill] in under a minute" | only when the Short actually teaches it |
| `value-start-here` | "If you're starting [activity], start here" | only for genuine first steps |

### 8. WARNING — name the mistake before the viewer makes it
| Anchor | Template | Notes |
|---|---|---|
| `warning-common-mistake` | "The mistake almost everyone makes with [thing]" | show the mistake, not just name it |
| `warning-costs-you` | "This habit is costing you [cost]" | the cost must be supported |
| `warning-dont-until` | "Don't [action] until you've [prerequisite]" | the prerequisite must be concrete |
| `warning-sign` | Describe the early sign that something is going wrong, then what to do | adaptation; not literal |

### 9. VERSUS — compare two things directly
| Anchor | Template | Notes |
|---|---|---|
| `versus-a-or-b` | "[Option A] or [option B]? It depends on [factor]" | the deciding factor is the payoff |
| `versus-difference` | "The difference between [group A] and [group B] is [difference]" | one difference, stated plainly |
| `versus-two-paths` | "Two ways to [goal]. Only one of them lasts" | say which lasts and why |
| `versus-side-by-side` | Put the two on screen at once and let the picture make the comparison | picture-led |

### 10. RELATABLE — start from a shared experience
| Anchor | Template | Notes |
|---|---|---|
| `relatable-you-know-when` | "You know when [familiar moment]?" | the moment must be specific, not a mood |
| `relatable-sign-you` | "Sign you're a [identity]: [telling detail]" | one telling detail beats a list |
| `relatable-used-to` | "I used to [old habit]. Now I [new habit]" | the change must be the lesson |
| `relatable-scene` | Put the viewer inside a familiar moment before naming the lesson | adaptation; not literal |

### 11. NEWS — something is new or has changed
| Anchor | Template | Notes |
|---|---|---|
| `news-just-changed` | "[Thing] just changed, and here's what it means for [audience]" | must be genuinely recent in the source |
| `news-new-way` | "There's a new way to [task]" | compare it with the old way |
| `news-reminder` | "Quick reminder: [timely fact]" | the fact must be timely and sourced |
| `news-first-look` | Show the new thing on screen first, then explain why it matters | picture-led |

### 12. COMMAND — tell the viewer to do one thing
| Anchor | Template | Notes |
|---|---|---|
| `command-do-this-first` | "Before you [action], do this" | the step must be fast to do |
| `command-try-this` | "Try this the next time you [situation]" | name the exact situation |
| `command-save-this` | "Save this for the next time you [situation]" | only when the Short is reusable reference |
| `command-stop-start` | "Stop [old action]. Start [new action]" | both halves required |

What Sniper is, what it includes, what it needs

Read this before you install, so there are no surprises about what it does and what it costs to run.

What it does

You give Sniper a recording and describe the result. It transcribes the recording locally, decides the cuts, writes an edit plan, checks that plan against its own rules, renders the video, inspects the rendered frames, and either fixes what it finds or tells you what it could not do. You get a finished final.mp4 and the editable project behind it.

What is included

ToolWhat it is for
ProducerThe main editor. Raw footage in, finished video out. Vertical Shorts (9:16) and full-length landscape videos (16:9).
SegmenterChops a long recording into rough clips for another editor. Deliberately rough: each clip keeps about five seconds of extra footage before and after, and starts on the nearest keyframe before that, so neighbouring clips overlap by those handles. A single recording is not re-encoded, so nothing is quality-lost; several camera angles are cut frame-accurately instead, re-encoding at the joins.
ClipperTightens one clip word by word and exports a frame-accurate Final Cut Pro timeline (FCPXML).

What Producer can do to a video

  • Cut dead air, filler and bad takes, and tighten the pacing.
  • Reframe landscape footage to vertical, anchoring on a detected face when there is a stable one, otherwise centre-cropping or blur-padding. This is a fixed frame per shot, not continuous subject tracking — shots with several faces, fast movement or someone leaving frame are worth checking.
  • Burn in captions that follow the words that survived the cut.
  • Add motion, graphics, transitions, b-roll placement and claim-checking cards.
  • Clean up dialogue and master the audio to a common streaming level (−14 LUFS).
  • Lay a music bed under it, ducked beneath the voice. Off by default.

What it does not do

  • It is not a one-button machine. A complete, unattended creator project has not been qualified end to end. You direct it and you review the result.
  • It does not copy another creator's style. It can measure a video you point it at and use the measurements as guidance. Reproducing a look is not a capability this release claims — the internal test cohort for that is 0 of 7.
  • It does not promise a view count, a growth rate or a fixed number of clips per recording. Choosing which moment is worth cutting is an editorial judgement.
  • It does not guarantee a turnaround time. See what to expect for the only timing figures that have actually been measured.

What you need

RequirementDetailCost to you
A MacmacOS 13.5 or newer on Apple silicon, or macOS 14 or newer on Intel. Setup detects the processor and selects the matching pinned runtime and browser. Sniper has run on the developer Apple-silicon Mac with macOS 26. Its Intel runtime and ffmpeg have passed their checks through Rosetta there, but installation on native Intel hardware is not yet qualified.—
MemoryNo minimum has been tested: Sniper has only run on a 64 GB Mac. Rendering does not start while macOS reports the Mac is short of memory, so on a Mac with less memory, close other large apps before a render.—
Disk spaceAbout 4 GB for the install and its tools (about 1.2 GB of that in ~/.project-sniper), plus room for your projects. Leave at least 20 GB free; a full-length render uses a lot of temporary space.—
An internet connection for setupSetup downloads Sniper's own tools (Python, Node, whisper.cpp, tesseract, yt-dlp, git — about 300 MB, each file checked against its recorded SHA-256), the rendering browser, the speech model and the JavaScript packages Sniper's scripts use; Sniper's own ffmpeg comes in this download. Nothing needs to be installed beforehand: no Homebrew, Xcode, Python or Node.Free
Your own Codex or Claude CodeThis is the part that thinks about your edit: you open the Sniper folder in Codex (ChatGPT plan) or Claude Code (Claude plan), desktop app or command line, signed in as you already use it, and ask. There is no extra Sniper processing fee and no Sniper sign-in. Sniper's own commands never call a provider. One optional thing can bill per use, on a key of your own: Deepgram transcription (a Deepgram key, and only when you approve it for an edit). If your Codex or Claude Code is itself signed in with an API key rather than a plan, your conversation with it bills that key, as it always would.You pay your provider directly. Their plan price, model access and usage limits apply.

About the subscription. Sniper works with either Codex or Claude. Aaron, who built it, recommends Codex with GPT-6 Astra based on his own edits — that is his preference from his own work, not a measured comparison, and not every plan includes every model. Both routes are supported and documented.

Your agent, your version. Sniper does not install or pin Codex or Claude Code: it works through whichever version you have. Its instructions and skills live in this folder, and every tool they run goes through ./sniper, which uses Sniper's own tools whatever else is on your Mac. Full qualification edits through each are tracked outside this package; PENDING-OWNER-DECISIONS.txt lists what is still open.

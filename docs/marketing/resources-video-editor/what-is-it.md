# What is Project Sniper?

Project Sniper is a local AI-assisted editing pipeline for turning raw
recordings into reviewed video. You describe the result; its supported lanes
plan, render, and QC the edit. The component mechanisms are implemented, but a
complete hands-off short/long creator-project cohort is not yet release
qualified.

It's really **four tools that share one workspace**, so you can go from a long raw recording all the way to a polished, captioned, ready-to-post cut.

## The four tools

### 🎛️ Producer — the main event
Add raw footage and choose the supported lanes you want on one card: cutting,
pacing, bounded reframing, captions, cards, motion, and audio. Producer can
build a **Short (9:16)** or a **Long (16:9)** candidate and stops explicitly
when a requested combination is unsupported or lacks required approval.

### 🎬 Segmenter
Got a two-hour recording? Segmenter rough-cuts it into individual clips you can actually work with — transcribe, let the AI find the segments, tweak the boundaries, export.

### ✂️ Clipper
Refine a single clip into a tight cut. The AI trims filler word-by-word; you fine-tune in a word editor and export a timeline for Final Cut Pro.

### 🔍 Frame Review
A fast quality check: scan a finished video for on-screen text mistakes — typos, spelling, broken formatting — and jump straight to each flagged moment.

## What makes it different

- **You direct; it edits.** Describe the result — *"cut a punchy 45-second short,"* *"clean up this talk"* — and it applies the supported cuts, timing, captions, and graphics.
- **Measured guidance, not a mimic promise.** Closed house looks and reference studies can guide planning; verified reference replication is not released.
- **Your footage stays yours.** Video never leaves your machine — editing and rendering happen locally. (More in the [FAQ](faq.md).)
- **Finish like a pro.** Hand the exact result to Palmier Pro for final color and export whenever you want more control.

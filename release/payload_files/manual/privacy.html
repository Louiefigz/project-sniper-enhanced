What leaves your Mac, and what does not

Checked against the code in this package, feature by feature. Read this before you edit anything confidential.

No feature of the app uploads a video or audio file. Rendering, speech-to-text and the edit itself run on this Mac. What does leave is text and still images, sent to the Codex or Claude subscription you chose, plus the separately optional paid features below if you turn them on.

Still images of your footage do leave. Before Auto Edit approves a video it runs a rendered review: Sniper takes still frames from the video it just rendered and sends them to your provider so it can check the result. This happens for trim-only edits too; there is no text-only mode.

The editing agents can read your project folder. The Codex or Claude session that writes and revises your edit plan works with file tools inside your project, footage and reference folders. Its instructions tell it not to send video or audio, but for these agents that is an instruction, not something the code can enforce. See the editing agents below.

The editing agents

Writing and revising the edit plan is done by a Codex or Claude session with tools, so it can read the transcript, the rules and the project. What the code allows today:

  • Codex runs in its own sandbox with a shell. The sandbox limits where it can write (the folders Sniper hands it), not which files it can read, so it could open any file your user account can read, including video files.
  • Claude is given the project, source-footage, snapshot and reference folders, file-reading tools, a few exact commands and write permission for the plan. It could read files in those folders, including video files.
  • The editor window you open with install/editor.command is the same CLI with its ordinary tools, working in the app folder.

The macOS video/audio sandbox cannot wrap these sessions: the provider CLI sandboxes its own tool commands, and macOS does not allow a sandbox inside a sandbox. If a still frame of a recording must never leave your Mac, do not edit that recording with Sniper; the rendered review sends frames whenever Auto Edit runs.

What that means in practice

  • Your words, as a transcript, go to your provider. So do still pictures of your edited video.
  • Your provider's data policy for your plan governs what happens to them. Sniper does not change it and cannot see it.
  • The optional paid features stay off unless you add a key and switch them on for a run. Nothing falls back to them.

Where your files live

~/ProjectSniper/<project>/
  source/     your footage and its transcripts
  producer/   edit_plan.json, base_final.mp4, final.mp4
  segments/   Segmenter exports
  clipper/    Clipper timelines

That folder is outside this package, so updating or moving the app never touches your projects. You can move it and point Sniper at the new location — see Licence, updates, backup and uninstall.

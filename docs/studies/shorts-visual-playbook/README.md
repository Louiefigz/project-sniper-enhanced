# Shorts visual reference library

18 selected treatments from the Nate Herk, Caleb Ralston and Lewis Mudrich footage already studied, plus [12 complete Nate story breakdowns](nate-sequences/README.md) and [8 additional Caleb/Lewis cases](authentic-expansion/README.md) with full-resolution frame sequences. The current September comparison set now has seven Caleb and seven Lewis sources. The original treatment IDs retain version `2026-09-10.1`; Nate cases use `2026-09-10.2` and the new cases use `2026-09-10.3`.

Start with [Format foundations](FORMAT_FOUNDATIONS.md): **message → viewing need → format → framing → development and readable hold → exit condition**. It compares split screens, full portraits, focused captures, diagrams, section markers and text-led footage, including when each choice fails. Creator names locate examples; the new source's message determines the treatment.

For produced Shorts, start with the [directing guide](nate-sequences/DIRECTING_GUIDE.md). It compares several examples of each decision: why this picture supports these words, where attention moves, why the person stays or leaves, what develops inside a held view, and what carries the story into the next shot. The complete cases preserve the reasoning that an isolated treatment image cannot.

The saved creator frames are source evidence for directing decisions. Adapt their useful relationships, hierarchy and information timing to our content and typography. Detailed notes make them searchable and explain the storytelling decision. The timestamped sequences preserve before/after context, while local source links allow closer motion inspection. Each entry links candidate HyperFrames mechanisms and states the work still needed. The hosted HyperFrames registry is primary; the legacy local item count does not limit native Shorts.

## Use during planning and QA

1. Find candidates by story job below. Open the selected full frame and its sequence with an image-viewing tool; read the paired entry. Text search alone does not count as visual review.
2. Select a small coherent family for the short. Inspect a complete case and at least one plausible contrasting example of its main story job. Record the reference/beat IDs, version and exact source-frame paths in the existing strategy/storyboard, plus why they fit the words, the new speech cues and any deliberate difference. One short may use several layouts; creator names are not whole-video presets.
3. Specify what changes on screen, what the viewer should understand, why the person stays or leaves, actual crop/pane geometry, action time and readable result hold. Two useful pane jobs still need deliberate framing and readable detail. Preserve useful authentic performance. Renew information through actions and results as well as changes of view; a new template every two seconds is not a universal rule.
4. Obtain the actual B-roll, website/demo capture or diagram inputs. Inspect the named catalog source and reuse/configure/compose before bounded custom work. An unresolved asset or mechanism stays visible in planning.
5. Compare the native Studio candidate with the same saved references at phone size, including entrance, readable state and exit. Check the hook's reason/lifetime, spoken alignment, captions, face/hand clearance and the delivered answer. Inspect source motion/audio whenever exact timing matters.

These are reference recipes and agent planning instructions. This library does not implement automatic image retrieval, template selection or a rendered style pack. Candidates remain unqualified until their actual adapted scene is checked. Original study coverage and confidence limits are linked at the end.

All 18 original selected frames and sequences were visually reviewed. The new eight-case expansion separately records complete 2 fps sheet coverage, 13 motion bursts and 12 individual native-frame spot checks. Source audio was acquired but not auditioned. Nate has machine-timed VTT; the original six Instagram cases use visible burned captions, and five of the eight new cases also have accepted local machine transcripts. No exact easing, word-lock, font identity or causal retention claims follow from this library.

Keep existing reference IDs stable. Add a version when revising interpretation or the selected target. Never silently replace reference pixels with a generated replica. A catalog code update requires re-inspection of the recorded source hash before reuse. The source videos and candidate code remain in their study artifact directories; the curated images and descriptions are stored together here.

## Repository media policy

The authored studies and source manifests are versioned. Extracted JPG frames
and contact sheets remain local under the repository's media policy. Their
paths in the manifests identify local evidence; a fresh checkout must restore
or regenerate that evidence before a visual-reference review can run. Missing
images must not be treated as inspected references.

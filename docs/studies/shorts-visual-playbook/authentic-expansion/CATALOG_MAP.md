# Turn the viewing need into a HyperFrames composition

The hosted **HyperFrames registry catalog is primary** for native Shorts.
Reuse the long-form catalog discovery, source inspection, asset binding and
Studio path. The old local integrated template count is neither a selection
boundary nor a measure of Shorts readiness.

Choose the message and format using [Format foundations](../FORMAT_FOUNDATIONS.md),
then search for its mechanism. The September 10 CLI searches for a branching
idea and a focused screen reported 399 catalog entries using word matching.
That is a discovery receipt, not 399 qualified scenes or evidence of a fresh
remote inventory fetch. Search ranking alone does not establish fit.

The exact saved implementations are recorded in [catalog-sources.json](catalog-sources.json).
These are inspected source candidates, not newly rendered adaptations. Reinspect
the source if its hash changes. Their behavior and gaps matter more than their names.

| Needed function | Candidate and observed source behavior | Required adaptation or limit |
| --- | --- | --- |
| Retain a central idea while related concepts arrive (CR07). | `constellation-hub`: configurable hub, comma-separated nodes, cue times, SVG connector drawing and node emphasis. | Useful for the branching phase. It does not supply problem + solution → resulting idea, followed by replacement of angle labels. Compose those semantic states and bind their actual speech cues. Size labels for the chosen pane and our font system. |
| Develop a branching diagram (CR07 alternative). | `flowchart-vertical`: fixed 1440×2560 sample with a root, branches, leaf reveals and a scripted text correction. | This is a concrete example, not a generic process engine. Replace the example topology/content and inspect its callback-based text changes for seeking before reuse. Its fixed portrait canvas does not automatically fit a half-height pane. |
| Present an actual screen or guide (LM04/LM06). | `browser-device-stage`: browser/window/phone framing, host-document template slots for `screen` and optional `screen-b`, staged entrance, optional fade-through swap. | Supply the actual inspected capture. Missing slots show a skeleton; that is not a completed asset. Configure geometry and crop. Its screen swap is not an in-place edit of a headline. |
| Move attention to the relevant control, row or result (LM06; compare N10). | `ui-focus-zoom`: host slot for the screen, anchor coordinates, zoom, cue, optional halo and clamped pan. | Supply the actual image/video/HTML and choose the relevant anchor. It does not detect a meaningful region, retrieve footage or prove the action/result match. Inspect the focused result at phone size. |
| Present a restrained title or ordinal (CR04/CR06/LM07). | `titlecard-calm`: separate kicker/headline, staged entrance, hold and exit. | The default is a whole card with a monospaced kicker and a delayed headline entrance. Configure/remove the kicker, typography, safe rectangle and timing. It is not automatically a caption overlay or immediately visible opening. |

Names beginning `native-` in the new cases are descriptive routes for existing
media, crop, text or caption responsibilities; **they are not hosted catalog IDs**.
Use the working shared media and speech-caption layers for those basic jobs.
Do not build a second caption engine or treat these labels as executable registry
lookups. Native support still needs to be checked against the actual writer.

Apply **reuse → configure → compose → bounded custom for an evidenced gap**.
The new source's words determine its states, inputs, branch count and holds.
Exact reproduction of a reference's yellow palette, texture or font is not a
reason to build custom motion. For a real gap, state precisely what the closest
candidate cannot do and keep the rest of the shared path.

Before a candidate is qualified, check its real assets, source-truth, pane
geometry, loaded fonts, readable states, seeking and native preview with audio.
This mapping does not implement general catalog binding in the V9 Shorts
prototype; it gives that implementation a concrete, source-inspected planning input.

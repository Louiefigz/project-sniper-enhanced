# Palmier hybrid layered repair plan

> **STATUS: ISOLATED EXPERIMENT / P5-BLOCKED.** The local mechanisms below are
> implemented or contract-tested, including scoped element replacement and a
> synthetic 14-minute exercise. They do not qualify a connected editable
> Palmier product. The dependable delivery is the approved exact `final.mp4`
> and its one-clip flat mirror. Representative connected short/long proof and a
> 30–60 minute endurance run remain open.

## Decision

The experimental design produces two coordinated artifacts from the same gated
`edit_plan.json`:

1. **Editable Build (experimental)** — persistent Palmier source/cut clips plus
   deterministic rendered graphic overlays. Use only in an isolated target
   until P5 connected qualification passes.
2. **QC Master (release-safe)** — one flattened, fully audited publishing file
   produced only after an operator-approved batch of changes.

The renderer owns card pixels. Palmier owns card timing/stacking. The element
ledger connects the two.

## Non-negotiable invariants

- Every editable element has a stable plan id.
- Every mutation starts from an exact project/timeline/fingerprint CAS.
- Rendered assets are content-addressed and carry codec/canvas/duration proof.
- Unchanged elements cannot be removed, moved, resized, or regenerated by a
  scoped repair.
- Source plan, gates, operation manifest, and prior authority are immutable
  content-addressed snapshots.
- No repair rewrites the approved QC master. It marks the master stale.
- Final publication receives one complete render and full-video QC.

## Delivery phases

### Phase 1 — card copy/style repair (local mechanism implemented)

- Record graphic id → clip id/media ref/hash/window/track after native placement.
- Refresh the current track from the stable clip id immediately before repair;
  insertion-era numeric indices are not durable.
- Render only changed `graphicsTrack[].spec` pixels.
- For an active presenter-hole comp, map only that card window through the cut
  spine and fill the registered hole with the measured live presenter before
  import. Palmier receives one self-contained card clip; the full base is not
  recomposited.
- Import and replace only the corresponding overlay.
- Handle Palmier auto-replacement and explicit old-clip cleanup.
- Recover interrupted mutation receipts from exact readback.
- Reject timing, kind, anchor, cut, motion, and lane changes.

### Phase 2 — graphic timeline deltas (local mechanism implemented, bounded)

- Add/remove cards with stable ids and versioned ledger bindings.
- Move same-duration cards without opening the renderer; duration changes render
  only the affected replacement asset.
- Batch up to 256 logical element changes into revision sets and checkpoint
  Palmier mutations in pages of at most 24.
- Tombstone removals so interrupted work cannot silently resurrect an old id.
- Reject stale element versions before opening the renderer.
- Recompute presenter recompose only when the changed card requires a different
  clear region. This remains a broader-revision boundary rather than an unsafe
  local mutation.
- Audit dirty windows at before/entrance/middle/exit/after frames, then still run
  one final full-video export and Audit B.

### Phase 3 — footage and dependent-lane deltas (analysis shipped; mutation gated)

- Replace one source/B-roll clip without rebuilding unrelated tracks.
- Refit captions, music automation, transitions, and motion only across the
  timing interval affected by a cut/ripple change.
- Persist dependency edges so downstream invalidation is explicit.
- Current code calculates the dependency closure and refuses cut/global changes
  as a broader rebuild. Native ripple mutation remains disabled until a live
  long-form proof verifies caption, transition, keyframe, and audio handles.

### Phase 4 — long-form endurance and parity (local mechanism proof only)

- Run a connected 30–60 minute editable build with at least 50 graphic
  elements.
- Modify one early, middle, and late card independently.
- Prove each repair invokes one graphic render and no base render/composite.
- Stop after import and after placement; resume without replay.
- Compare an untouched Editable Build export with the deterministic QC Master at
  fixed frame/fps/color/audio tolerances.
- Render and audit the full QC Master once after the repair batch.

The deterministic suite exercises a synthetic 14-minute plan with 50 graphics
and verifies scoped stable-id repair while unrelated units are reused. This is
a local mechanism proof, not a connected Palmier build and not a 30–60 minute
endurance result. The connected endurance run and representative short/long
qualification are still required.

## Edit routing

| Requested change | Fast path | Broader work |
|---|---|---|
| Text/color inside the same card | One card replacement | None |
| Presenter missing from an unchanged registered hole | One isolated presenter-card replacement | None |
| Different card kind/anchor | Replace only when no presenter recompose dependency exists | Card + presenter recompose otherwise |
| Same-duration card move | One native move, no asset render | Changed-window audit |
| Duration-changing card timing | One card replacement | Presenter-dependent timing remains blocked |
| New/removed card | One add/remove plus versioned ledger/tombstone | Presenter-dependent additions remain blocked |
| Native text copy | One `update_text` operation | Style/timing changes remain blocked |
| Several independent changes | One paged revision set | Conflicts on one id fail before mutation |
| Footage replacement | No | Source clip + dependent lanes |
| Cut/ripple timing | No | Affected interval and downstream timing |
| Final publish | No iterative composite | One complete master + full QC |

## Definition of done

Before editable/hybrid delivery can leave isolation, a two-word change on a
long timeline must:

- leave the source/base fingerprint unchanged;
- resolve exactly one graphic asset (one render on a miss, one cache hit on a hit);
- mutate only the ledger-bound Palmier element;
- preserve every unrelated clip in readback;
- survive stop/resume without duplicate clips;
- require no flattened-master render until explicit finalization.

The canonical `edit_plan.json` never carries Palmier-only `persistentText`.
Native text belongs to the revision-set sidecar; legacy `persistentText` is
excluded from render hashes and remains an unknown parity lane, so it cannot
pretend to exist in an in-house master.

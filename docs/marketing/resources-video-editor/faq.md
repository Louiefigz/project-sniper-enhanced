# FAQ & troubleshooting

## Is my video private?

Yes. Your footage stays on your machine — transcription and rendering happen locally, and only the **text** (the transcript and the edit plan) is sent to the AI to make decisions. Your raw video is never uploaded. *(The one exception is the optional Frame Review text-check, which sends still images — never the video — to read on-screen text.)*

## Where do my files go?

Every project gets a folder at **`~/ProjectSniper/<your-project>/`**. Your finished video is `final.mp4` inside that project's `producer/` folder.

## Can I work on more than one project at once?

Keep as many projects as you like and switch between them freely. Run **one active edit at a time** — start the next when the current one finishes. (Only one edit can run per project at a time.)

## What do I need to run it?

A Mac and Project Sniper installed. Palmier Pro is optional for finishing and
does not need to stay open while Sniper renders. A few free local tools (for
transcription and rendering) are set up once during install. Full setup steps
are in [Getting started](getting-started.md).

## The edit stopped partway — did I lose it?

No. Edits keep running even if you reload the page or restart, and if one is interrupted you'll see a **Resume** option that picks up where it left off.

## Can I change the edit after it's done?

Yes — strike words to cut them, drag graphics, adjust audio, or ask for changes
in plain language. Eligible bounded changes reuse unaffected work. A broader or
unsupported change may require a larger rebuild or stop for approval; the
receipt tells you which happened.

## It didn't do something I asked for.

The editor is honest about its limits — if it can't do something, it says so rather than faking it. Read the message it gave you; often it's simply asking you to pick a style or confirm a choice first.

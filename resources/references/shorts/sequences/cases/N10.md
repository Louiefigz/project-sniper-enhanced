# N10 · Mark the one word that carries the point

Original reference rendered from Project Sniper's own templates. The copy in the pictures is illustrative; a real edit uses the speaker's words.

**Lesson:** When a sentence on screen has one word that matters, draw attention to that word after the sentence has been read, not before.
**Opening:** The full sentence appears unmarked.
**Story arc:** sentence read -> emphasis drawn on one word -> hold
**Payoff:** The emphasised word is the last thing that changes.

**Catalog:** marker-highlight, underline-circle, hw-callout-circle

## N10-B01 — Read the sentence first

**On screen:** The line appears plain.

**Why:** The viewer needs the whole thought before the emphasis means anything.

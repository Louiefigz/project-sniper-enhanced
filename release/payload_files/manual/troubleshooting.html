When something goes wrong

What to expect, what the checker tells you, and how to send something useful if you get stuck.

First move, always

Ask your agent to run ./sniper doctor (or double-click install/doctor.command).

It asks the product's own code which browser, ffmpeg and speech model a render would actually use, and prints each one. It marks a line FAIL only for something that has to work, GATED for an optional feature that is not installed, and INFO for something worth knowing. If every required line passes, the install is fine and the problem is in the edit, not the setup.

The media admission (real sample) line runs a generated sample clip through the same admission step your footage goes through. If it fails, Producer cannot start an edit, and the line says why. What this candidate does and does not do yet is listed in PENDING-OWNER-DECISIONS.txt.

If it happens again on the same file, try another network and run install/diagnostics.command.
Sniper's own tools — changed since they were installed …; reinstalling them. A file in ~/.project-sniper was changed or removed.Nothing to do: the installer puts the tools back from the checked downloads.
Sniper's own tools are not installed yet. or Sniper's own Node cannot be used: … ~/.project-sniper was removed or damaged.Ask your agent to run ./sniper setup (or double-click install/install.command); it checks every tool file and reinstalls what is missing or changed.
Another Sniper installer is setting up the same tools; waiting …Two Sniper folders are being set up at once; they share the same tools.Nothing to do: the second one continues when the first has finished.
no cached chrome-headless-shell foundThe rendering browser is missing. Sniper never downloads one mid-render on purpose.Run ./sniper setup again; step 5/8 downloads it and checks its SHA-256.

kernel memory pressure is warning (or critical), system memory headroom is below policy, physical memory occupied by the compressor exceeds policy macOS reports the Mac is short of memory, so Sniper does not start a render rather than slow the Mac down or fail part-way.Quit other large apps (browsers with many tabs, other video or design apps), wait a moment, and run the step again.
The folder path contains one of , ' : \ …Those characters break the audio-cleanup filter, which embeds this folder's path.Move the folder somewhere without them. Spaces, accents, $ and quotes are fine.
A render stops and reports a problemWorking as designed. Sniper stops rather than shipping something it could not check.Read the message: it names the lane and the reason. Most are a request to pick a style or confirm a choice.
Not enough disk spaceA long render needs tens of GB of temporary space. Let running edits finish, then install/clean-caches.command shows what can be freed and how big it is, and never touches your footage, plans, finals or unsynced edits.

What to realistically expect

The only timing on record is Aaron's own: he fully edits a ten-minute video — motion graphics, cuts, trims, audio correction, b-roll — in under three hours, and estimates Sniper saves him about 85% of the effort versus editing it by hand. That is one person's report about his own work on his own machine. It is not a promise about your recording, your Mac or your provider plan, and no typical buyer runtime has been measured. Your first edit will take longer than your tenth, because you are learning what to ask for.

  • Transcription is local and roughly real-time-ish on Apple silicon; a 30-minute recording is minutes, not seconds.
  • Planning and review happen in your conversation with your agent. They are the slow part, and your plan's rate limits apply.
  • Rendering is CPU and disk heavy. Expect the fans.
  • Keep the conversation open while a render runs; if a step stops, ask your agent to run it again — finished stages are reused.

Sending something useful

install/diagnostics.command

This writes a folder to your Desktop containing structured facts only: this build's RELEASE.json, your macOS, Node and Python versions, the checker's report and the installer's own step log. It does not copy footage, transcripts, edit plans, keys or logins, and your conversation with your agent stays in your agent. Read it before you send it.

Support is not settled for this candidate. There is no support address in this package because the support route and response commitment have not been decided. Do not treat any address you find in the source as a support channel.

# A creator label is too broad to choose a Short's format

The September 10 reference expansion added four Caleb Ralston and four Lewis
Mudrich reels, bringing that current comparison set to seven each. The extra
examples changed the useful question from “which creator style?” to “what does
the viewer need to see during this thought?”

[CR07](../studies/shorts-visual-playbook/authentic-expansion/cases/CR07.md) gives
its upper half to a diagram: problem plus solution produces an idea, which
branches into angles and content. The lower half preserves matching hand
gestures. Around 18.6 seconds it returns to a full portrait for qualification.
[CR04](../studies/shorts-visual-playbook/authentic-expansion/cases/CR04.md), from
the same podcast context, explains a simple exercise through the conversation.
The relationship to explain, rather than the creator, distinguishes the choices.

Likewise, [LM06](../studies/shorts-visual-playbook/authentic-expansion/cases/LM06.md)
needs visible ad examples, metrics and a website edit. [LM07](../studies/shorts-visual-playbook/authentic-expansion/cases/LM07.md)
uses walking delivery and gestures for an argument about website trust. Matching
the noun “website” to a generic screen would miss the distinction.

The reusable planning record is:

```text
message → viewing need → format → actual crop/pane geometry
        → meaningful development → readable result hold → exit condition
```

The geometry is essential. Two useful pane jobs can still produce a poor Short
if the presenter is tiny or the screen's decisive detail is unreadable. A valid
mechanism does not qualify the composition. Source frames should be inspected
individually as well as in chronological sheets; the expansion's full-frame
review corrected a small-sheet reading of a laptop as a phone.

Use these decisions as conditional examples. Do not convert CR07's duration into
a global split-screen timer, or turn a rejected split into a presenter-only
fallback. Do not use this research as evidence of retention causality, exact
fonts or a passed render. The practical guide is [Format foundations](../studies/shorts-visual-playbook/FORMAT_FOUNDATIONS.md).

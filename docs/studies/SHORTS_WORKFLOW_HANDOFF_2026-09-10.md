## Required planning process

1. Establish the retained lesson, initial uncertainty and earned payoff from the
   actual source speech. Preserve context and show the user strong moments when
   selection remains open.
2. Develop written-hook options using eligible YouTube title formulas. Pair each
   with an actual recorded opener and a first visual that opens the same question.
   A sentence generated in a planning field is not newly available source audio.
   Record the selected hook's reason to stay and its removal cue.
3. Plan the visible story before choosing item IDs. For each meaningful beat, name
   the words, viewer question, visible object/action/result, view, attention target,
   reason for a move/hold, readable result time and handoff to the next thought.
4. Choose full presenter for useful performance, conviction or interpretation;
   split only when both panes contribute; full visual when reading or following
   the action needs the frame. Preserve useful pauses and gestures.
5. Resolve the real material and execution route. Inspect the exact catalog source,
   slots and controls. Identify assets, portrait readability and any bounded custom
   work. Prove only an uncertain mechanism in a small preview when necessary.
6. Assemble from the resolved plan in editable native Studio. Keep source speech,
   footage timing, captions and graphics coherent. Do not overwrite Studio edits
   through the legacy flattened-base review path.
7. Review with actual audio and at phone size. Verify the opening, word-picture
   alignment, readable states, transitions, payoff, caption hierarchy and face/hand
   clearance. Check playback, seek, restart and reload; inspect an encoded result
   when one is requested.
8. Reuse transcription, selected timing, assets and unaffected scenes during edits.
   Refresh dependencies when source cuts change. Measure selection, sourcing,
   assembly, QA and encoding separately instead of promising an arbitrary runtime.

For “video editing goes through five steps,” show one recognizable clip/project

# Reference style packs require frame coverage and independent reviews

## The failure mode

Aggregate reference metrics can prove cadence while still losing the edit's
actual vocabulary. “Eight graphics per minute” does not identify whether those
graphics were comparisons, evidence rails, progressive lists, or decorative
labels. Three entrance/settled/exit images can also miss a stagger, overshoot,
or one-frame transition defect between those samples.

## The contract

Treat reference learning as two evidence layers:

1. Analyze every source-cadence frame deterministically for cuts, motion,
   changed regions, text, and boundary events.
2. Visually review every frame of every detected event window, including a
   three-frame lead and six-frame tail. Cover non-event spans with start/mid/end
   representatives so the coverage ledger has no holes.

Review the resulting sheets twice. The mechanics pass runs chronologically and
measures geometry, phase timing, easing, typography, color relationships, and
occlusion. The editorial pass runs in reverse order from a fresh context and
classifies information form, semantic purpose, progression, and template fit.
The two passes share only a small classification schema. Any disagreement
requires a third evidence-based adjudication.

## Why template proof is separate

Seeing a comparison rail does not prove that an existing `comparison-bars`
renderer reproduces it. Every graphic-family review item needs a binding to a
real template and an existing rendered proof. The binding says `matched` or
`built` and `structureOnly:true`; it never transfers reference identity, copy,
claims, assets, fonts, colors, footage, or music.

## Release boundary

A reusable style pack is valid only when it binds:

```text
sourceHash + deepStudyHash + complete worklistHash
+ mechanicsReviewHash + editorialReviewHash [+ adjudicationHash]
+ templateRegistryHash
```

Unclassified motion, uncovered frames, incomplete reviews, classification
disagreement, or a missing template proof blocks compilation. A production plan
then binds each derived graphic, transition, and motion row back to a reviewed
grammar window before Palmier mutation.

## When not to use it

Do not pay this cost for a disposable inspiration board or a loose mood
reference. Use it when the operator asks to mimic an edit, save reusable
templates, or promote a reference into production authority. One reference may
create a reference-bound mimic pack; a durable house style still requires
multiple references and variance analysis.

# N06 · I Build Features Just By Talking to My Code

[Source Short](https://www.youtube.com/shorts/bzSN73XXiC4) · [Local source video](/Users/aaronfigueroa/development/demos/YT-Automation/PROJECT_SNIPER/artifacts/nate-herk-30-shorts-study-2026-09-10/corpus/06-bzSN73XXiC4/source-visual-current.mp4) · [Structured case](/Users/aaronfigueroa/development/demos/YT-Automation/PROJECT_SNIPER/docs/studies/shorts-visual-playbook/nate-sequences/cases/N06.json) · [Sequence index](../README.md)

30.100s · 18 directing beats · version 2026-09-10.2

**Lesson:** A process short can make an abstract interaction understandable by showing the trigger, the complete input, questions, approval and visible output. The input needs a sustained read window, and every later result must belong to that same input.

**Opening:** The surprising spoken premise is talking to code. A /voice title and headphones on a product mascot cue listening, then a Space keycap identifies the trigger before the input window appears.

**Story:** Voice premise → spacebar action → long prompt accumulation → plan/activity montage → questions → research phase → approval condition and human approval illustration → model identity → build/test montage → website tour → completion cue → teammate metaphor → product CTA.

**Payoff:** The short makes voice-to-request and the intended process stages recognisable. It does not close the opening dashboard request with a matching dashboard result: the shown output is a Mars registration website. Approval order, actual clarifying-question direction and successful verification are also not demonstrated cleanly.

**Why study this case:** Provides the strongest contrast to a two-second editing metronome: one input scene holds for more than six seconds after its brief entrance. It also distinguishes a whole-window enlargement, small keycap emphasis, accumulating questions, native UI scrolling and completion overlays from separate layout changes.

**Review limits:** All four complete chronological 2 fps context pages were inspected, plus three narrow 10 fps strips regenerated from explicit decoded source frame indices and a full-resolution output frame. No audio audition in this expansion. Spoken ideas are paraphrases of timed caption sidecars checked against the visible sequence. Beat boundaries remain approximate editorial partitions, generally within 0.5-second contextual spacing; exact frame-index strip labels support only the inspected intervals. No easing or word-perfect synchronisation is claimed. Machine captions extend beyond the visual duration; coverage ends at 30.1 seconds. These are source observations and proposed planning decisions, not a rendered replica or qualified template.

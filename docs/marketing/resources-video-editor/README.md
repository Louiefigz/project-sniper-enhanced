# 🎬 Project Sniper — Guides

Project Sniper can turn raw footage into social-ready shorts and long-form
videos through its supported local editing lanes. The bounded cut, caption,
motion, render, and repair mechanisms are implemented; representative complete
short/long product qualification is still open.

**New here?** Read [What is Project Sniper](what-is-it.md), then [Getting started](getting-started.md) for your first edit.

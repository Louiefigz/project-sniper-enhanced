Fonts in this folder (all SIL Open Font License 1.1; each licence file carries the
font's own name-table copyright line):

Inter-Regular.ttf, Inter-Bold.ttf
  Inter 4.1 (font version 4.001), Copyright 2016 The Inter Project Authors,
  https://github.com/rsms/inter. Licence: Inter-OFL.txt. Used by the caption
  renderer (libass) and embedded in templates/motion/tokens.css as the text face.

Caveat-700-latin.woff2
  Caveat 2.000 (variable weight, latin subset), Copyright 2014 The Caveat Project
  Authors, https://github.com/googlefonts/caveat. Licence: Caveat-OFL.txt.
  Embedded in templates/motion/tokens.css as --font-hand for the hand-drawn (hw-*)
  compositions. Obtained from the HyperFrames catalog mirror; the bytes are unmodified.

ChunkFive-Regular.otf (+ ChunkFive-OFL.markdown)
  ChunkFive by Meredith Mandel / The League of Moveable Type. No longer used: the
  motion templates now use Bricolage Grotesque as their display face. Kept in the
  source tree only; withheld from the buyer package (release/package_spec.py).

The motion templates also embed Bricolage Grotesque and IBM Plex Mono from
src/app/fonts/ (licence files beside those fonts).

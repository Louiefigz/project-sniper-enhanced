## Verdict rules

- **PASS** requires executable enforcement and passing tests for the complete
  wording of that exit.
- Evidence from separate tests may compose only when the same contract binds
  the surfaces together. A collection of isolated capabilities does not prove
  one claim-sized fixture.
- A fail-closed native Palmier disposition is honest delivery behavior. It
  does not prove native sample-exact Palmier L/J support.
- Controlled media can prove declared timing, preservation, durability, and
  selected-source A/V mapping. It cannot prove creator-speech ASR quality,
  face/mouth/phoneme inference, or perceptual lip sync.
- The released visual gate proves selected-source A/V temporal mapping inside
  a caller-supplied normalized region. It is not face or mouth detection,
  phoneme inference, lip-reading, semantic audibility, or operator audition.

## What is executable now

The first-class route has distinct authority transitions:

1. `analyze` resolves an exact occurrence and enumerates deterministic local
   candidates against the selected V2 revision.
2. `prepare` produces immutable diagnostic and full-plan candidate media
   without changing the selected head.
3. `review` advances only the exact prepared candidate to `CUT_REVIEW`.
4. `approve` seals operator selection and automated QC evidence.
5. `execute` promotes only that sealed package, activates the exact media and
   render graph, and returns the head to `PICTURE_LOCKED`.
6. `reopen` is a separate operation for exact impossible cases. It moves the
   project back to `CUT_DRAFT` and lists the dependency impact without
   pretending a ripple edit already happened.

The audio-only V2 lifecycle fixture uses real H.264/AAC media. Its selected
promotion proves that a prior J-cut, graphics, music, karaoke captions, plan
object, timeline map, render graph, and projection remain bound to the same
intended authority. The separate picture-changing path has the narrower lane
admission stated below.

Picture-changing repair now has a separate production path:

- the controller—not the caller—derives the unique later-take candidate and
  binds its exact source/frame/sample/output identity;
- a pinned controlled visual gate proves selected-source A/V temporal mapping
  within `visualSpeechRegion`;
- graph staging binds the exact ACTIVE parent, while a pre-copy verifier
  reopens and rehashes the parent graph, receipt, root media, plan, source, and
  current toolchain;
- only the verified candidate can become active through a post-copy,
  expected-parent activation inside the project mutation lease.

That picture terminal is intentionally narrow: 30 fps, 48 kHz, one source,
speed 1, zero residual, source extension at the target edge, and exact silence
reclaimed from the opposite terminal boundary. It accepts no existing lead,
interior repair, multi-source repair, retime, or non-grid case. Plans carrying
captions or `dialogueCaptionAuthority`, graphics, b-roll, title cards,
transitions, baseline/reframe/punch-ins, music, gain/enhancement, or any
unknown lane fail closed. The restriction prevents raw replacement pixels
from erasing a previously burned overlay; it is not proof of general
dirty-window layered recomposition.

# LM07 · A website argument that stays with the person

Version `2026-09-10.3` · [Original reel](https://www.instagram.com/reel/DcWrkGgP0h0/) · 37.583s

**Message:** A cold visitor needs visible reasons to trust you near the beginning of a landing page.

**Story:** Landing-page problem → trust objection → visitor perspective → buried proof problem → move relevant proof earlier → mobile consideration.

**Format foundation:** Mentioning a website does not automatically require a screenshot. This source is a persuasive explanation about the visitor's perspective, carried by movement, gestures and a coherent spoken argument. Compare LM06 when the viewer actually needs to see a control change.

**Good adaptation:** Preserve body and hand gestures while keeping the face legible; the source uses a moving full-height composition rather than a tiny contained landscape. Clear the opening heading when the trust point is established. If our lesson becomes a specific before/after page demonstration, obtain that page and earn a new visual format then.

**Limits and counterexample:** Do not draw a generic page just because the transcript says landing page. The source includes an unverified drop-off percentage; do not promote it into an authoritative chart. Reframing is still required when adapting landscape source footage.

**Text roles:** Large green key phrase in a white opening heading; ordinary white speech captions thereafter. The top title clears around the early trust pivot rather than staying for the whole reel.

**Compare:** LM06, A05, CR04. See [Format foundations](../../FORMAT_FOUNDATIONS.md).

**Possible mechanisms:** `native-presenter-crop`, `native-captions`, `titlecard-calm`. These require configuration/composition and review; they are not rendered matches.
